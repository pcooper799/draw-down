# Draw Down download page

Static landing page for attendees/operators.

## Host

1. Configure the GitHub repo: from the project root run  
   `npm run release:repo -- your-user/draw-down`
2. Publish a GitHub Release with Windows `.exe` assets (tag `v0.1.0` or run the Release workflow).
3. Enable GitHub Pages for this `website/` directory (or copy it to `docs/`).
4. Share: `https://your-user.github.io/draw-down/`

Until Pages is live, share `https://github.com/your-user/draw-down/releases/latest` directly.
